# Cola de contenidos

La lee el piloto automático de contenidos (`docs/content-autopilot.md`) en cada ejecución. Cada tema lleva datos de OpenSEO y la página de servicio a la que debe llevar, porque el objetivo es conseguir llamadas, no tráfico suelto.

## Cómo dirigirla

- **Orden = prioridad.** El piloto escribe el primer tema con estado `aprobado` y, si no hay ninguno, el primer `propuesto`. Para cambiar el orden, mueve los bloques.
- **Estados:** `propuesto` (lo propuso el piloto o Claude), `aprobado` (adelántalo), `necesita input` (falta una decisión tuya y el piloto lo salta), `en PR` (borrador abierto), `publicado`, `vetado` (no lo escribas nunca).
- **Tu aprobación real es el merge.** Cada artículo llega como un pull request con la versión en inglés y en español. Si haces merge, se publica solo en su fecha. Si lo cierras, el piloto pasa al siguiente tema; deja un comentario en el PR o una nota aquí si quieres otro enfoque.
- Las cifras son búsquedas mensuales estimadas: EE. UU. en inglés y España en español. KD es la dificultad (0 a 100). Las posiciones salen de comprobaciones en vivo con la fecha indicada.
